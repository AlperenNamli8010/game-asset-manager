Indie Game Asset Manager

Bağımsız oyun geliştiricilerinin (Indie Developers) projelerinde kullandıkları ses, 3D model, script, animasyon ve arayüz (UI) tasarımlarını tek bir merkezden, lisans türleri ve formatlarıyla birlikte yönetebilmelerini sağlayan web tabanlı bir CRUD uygulamasıdır.

Özellikler
* Güvenli Kullanıcı Kaydı ve Girişi (password_hash & session kullanımı)
* Kişiselleştirilmiş Kontrol Paneli (Her kullanıcı sadece kendi varlıklarını yönetir)
* Varlık Ekleme (Create), Listeleme (Read), Güncelleme (Update) ve Silme (Delete) işlemleri
* Mobil Uyumlu Modern Arayüz (Bootstrap 5)
* Yalın PHP ve PDO ile güvenli veritabanı işlemleri (SQL Injection koruması)
